# Interface

네트워크 및 음성/게임 상태 이벤트를 전달하기 위한 리스너 인터페이스 모음입니다.

## Scripts

* **ITimerListener**
  타이머 변경 시 호출되는 이벤트 인터페이스 

* **IConnectionListener**
  플레이어 접속/퇴장 상태 변경 시 호출되는 인터페이스 

* **IParticipationListener**
  Vivox 음성 채팅 참가자 변경 시 호출되는 인터페이스 

* **IServerStateListener**
  서버 상태 변화 시 호출되는 인터페이스 

* **ISpeechListener**
  음성 발화 감지 시 호출되는 인터페이스
