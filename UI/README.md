# UI

게임 전반의 UI 표시, 상태 반영, 인터랙션을 담당하는 스크립트 모음입니다.

## Scripts

* **UIManager**
  게임 상태에 따라 전체 UI(CanvasGroup)를 전환하고 페이드 애니메이션을 관리하는 핵심 클래스 

* **PlayerUIView**
  플레이어 HUD(배터리, 상태 아이콘 등) 표시 및 상태 변화 처리 클래스 

* **TimerView**
  서버 타이머 값을 받아 UI에 표시하고 상태에 따라 노출을 제어하는 클래스 

* **MapInfoView**
  세션 시작 시 현재 맵 정보를 페이드 효과로 표시하는 클래스 

* **SpectaterView**
  관전 상태에서 대상 플레이어 정보를 표시하는 UI 클래스 

* **VoiceChatView**
  Vivox 참가자 목록을 UI로 표시하고 발화 상태를 반영하는 클래스 

* **Chat**
  음성 채팅 발화 상태에 따라 아이콘을 표시하는 UI 컴포넌트 

* **AlarmView**
  플레이어 접속/퇴장 및 서버 상태 변화를 알림 메시지로 출력하는 클래스 

* **MainMenuView**
  메인 메뉴 UI 및 화면 전환(시작, 설정, 종료)을 처리하는 클래스 

* **CheckOutView**
  게임 종료 후 정산 결과(플레이어 상태 및 노트)를 표시하는 UI 클래스 

* **CheckOutManager**
  플레이어 데이터 기반으로 정산 결과 UI를 구성하고 관리하는 클래스
